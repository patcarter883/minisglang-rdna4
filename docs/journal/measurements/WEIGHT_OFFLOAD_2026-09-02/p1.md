## HIP device 0 — AMD Radeon RX 9070 XT (`gfx1201`, PCI `0000:03:00.0`)

VRAM 15.86 / 15.92 GiB free at start. HIP reports 32 multiprocessors (WGPs on RDNA, not CUs). Verdict: **PASS**.

**PCIe path:** governing link is root port `0000:00:01.1`, measured **UNDER LOAD** at **x8 @ 32.0 GT/s** (~31.51 GB/s theoretical). These ports down-train at idle (states seen: x8@32.0GT/s), so this is the max observed while the copy engine was saturating the link, not an at-rest reading. The card's own function advertises its on-package bridge as x16; that is not the slot link and bounds nothing.

### Findings

- **vmm_host_location_not_honored** (decision-critical): hipMemCreate(location.type=hipMemLocationTypeHost) returned hipSuccess for every chunk, and hipMemMap/hipMemSetAccess succeeded, but the pages consumed VRAM rather than host RAM  
  *Consequence:* the plan's mixed device/host single-VA stack (sections 2 and 9) has no host tier through this API; any 'host-page read bandwidth' taken from this arm would be an HBM number in disguise, so it is excluded from the verdict
